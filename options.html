PII Guard settings

PII Guard checks text in web form fields for common patterns that may indicate personal information.

What it checks

  • Email addresses
  • Phone-number-like strings
  • 12-digit Aadhaar-like numbers (Verhoeff checksum validated)
  • PAN-like strings
  • 13–19 digit payment-card-like numbers
  • Six-digit Indian PIN codes
  • US Social Security Numbers (SSN)
  • Passport numbers
  • Driving License numbers
  • Voter ID (EPIC) numbers
  • Indian IFSC codes
  • International Bank Account Numbers (IBAN)
  • US ZIP+4 codes
  • Date of Birth patterns
  • IPv4 addresses
  • Cryptocurrency wallet addresses

Priority & Danger Levels

  • Critical / Danger (Red Alert): Crucial financial & identity data including Credit/Debit Cards, SSN, Aadhaar, Passport, PAN, IBAN, and Cryptocurrency wallets.
  • Medium Risk (Amber Warning): Driving Licenses, Voter IDs, Bank IFSC codes, Phone numbers, and Dates of Birth.
  • Notice / Low (Blue Notice): Email addresses, IP addresses, and Postal PIN/ZIP codes.

Important limitations

  • This is a heuristic detector, not a guarantee that all PII will be detected.
  • It can produce false positives (for example, ordinary numbers) and can miss unusual formats.
  • It warns; it does not block form submission or remove data from a website.
  • Some browser-internal pages, Chrome Web Store pages, and restricted frames do not allow extensions to run.
  • Because this extension runs on all websites, it requests broad site access. Review the code before installing it.
